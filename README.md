# Schlange
Schlange é um simples "jogo da cobrinha" feito por VoiidHead para testar suas habilidades com a biblioteca Pygame do Python  
  
O jogo foi feito com base na Community Edition do Pygame.  
O código do jogo não é muito legível devido a um mau costume, mas há uma [versão legível comentada](https://github.com/VoiidHead/Schlange/blob/50e8e85f16c0a7a978026c6f7e2a600529d412e9/C%C3%93DIGO%20LEG%C3%8DVEL%20AQUI/schlange_legivel.py) disponível nesse repositório
